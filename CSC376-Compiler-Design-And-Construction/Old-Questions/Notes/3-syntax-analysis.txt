Syntax Analysis: FIG
- gets input from token and generates syntax / parse tree
- checks if string can be generated by grammar of source language
- reports syntax errors
- performs error recovery

Limitations of Parser:
- variable re-declaration
- variable initialization before use
- data type mismatch

Error Handling:
- lexical, misspelling keyword
- syntactic, arithmetic expression with unbalanced parenthesis
- semantic, operator applied to incompatible operand
- logical, infinite recursive call

Context Free Grammar (CFG):
- 4 tuple:
	V : syntactic variables denoting set of strings
	T : basic symbols from which strings are formed
	P : specifics manner in which V & T can be combined  to from strings
	S : starting symbol

Left Recursion:
- non-terminal A such that there is a derivation A → Aα for some string α
- production A → Aα | β it can be replaced with a sequence:
	A → βA'
	A' → αA' | ε

Left Factoring:
- production A → αβ1 | αβ2 , can be rewritten as:
	A → αA'
	A' → β1 | β2
Numericals:
- Top-Down Parser:
	- Recursive Descent
	- Predictive

- Bottom-Up Parser:
	- SR
	- SLR
	- LR
	- LALR
